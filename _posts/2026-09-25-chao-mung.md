Đây là nơi ghi lại những nội dung đã đọc, đã học, và đúc kết lại theo cách hiểu của riêng mình.

## Cách thêm bài viết mới

Tạo một file mới trong thư mục `_posts/`, đặt tên đúng định dạng `NĂM-THÁNG-NGÀY-tieu-de-khong-dau.md`, ví dụ:

```
_posts/2026-10-02-doc-ket-ve-thoi-quen.md
```

Đầu file khai báo tiêu đề, ngày, tag (phần giữa hai dòng `---`), phía dưới viết nội dung bằng Markdown bình thường:

```markdown
---
title: "Tiêu đề bài viết"
date: 2026-10-02
tags: [đọc-sách, năng-suất]
---

Nội dung bài viết ở đây — **in đậm**, *in nghiêng*, danh sách, link đều dùng được.
```

Lưu file, `git add` / `git commit` / `git push` như các repo khác — GitHub tự build và xuất bản, không cần cài gì thêm ở máy.
